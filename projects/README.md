# Projects Folder

Use this folder for individual portfolio projects.

## Suggested layout

projects/
├── project-template/
│   └── index.html
├── student-portal/
│   └── index.html
├── online-store/
│   └── index.html
└── library-system/
    └── index.html

Each project can have its own page, screenshots, and details while still sharing the same global portfolio styles.
